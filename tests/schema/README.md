# CoT schemas

The `.xsd` files and `types.txt` are the MITRE Cursor on Target schemas marked
"Approved for Public Release; Distribution Unlimited", as published in
https://github.com/deptofdefense/AndroidTacticalAssaultKit-CIV/tree/master/takcot/mitre
(file names shortened). `cot-all.xsd` includes them for validation.
